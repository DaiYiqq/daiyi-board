DY Board 是一款面向教学的一体化白板与展台演示软件，提供乳白液态玻璃界面、压感书写、文档摄像展台、课程表与课堂工具等能力，支持 Windows、macOS、Linux 与 PWA。

目前支持 Windows 10/11、macOS 12 及以上（Apple 芯片与 Intel）、主流 Linux 发行版（AppImage / deb / rpm），以及免安装的 PWA 网页版。

不会。DY Board 遵循本地优先原则，所有板书、批注、展台视频与照片仅在本机处理，软件不会上传任何个人数据，也没有账号体系。

每个发布包都使用 Cosign 进行无密钥签名，并附带 SHA-256 校验值。你可以在安装前核对，确保安装包来自官方且未被篡改。

桌面端内置自动更新，新版本发布后会自动静默推送，无需手动重新下载。你也可以随时到 GitHub 仓库的 Releases 页面获取最新安装包。

PWA 是渐进式网页应用，用支持的浏览器打开网页版后点击“安装”即可作为独立应用使用。DY Board 的 PWA 支持离线运行，断网也能照常使用。

DY Board 是开源项目，欢迎在 GitHub 仓库提交 Issue 反馈 bug 或提出新功能建议，也可以通过 Pull Request 直接参与改进。
