关于 DY Board

由一名开发者，为课堂而做

DY Board 不是一个公司的产品，而是一个独立开发者对“好用的教学工具应该是什么样”的回答——免费、本地优先、且完全开放。

用户协议与隐私说明

  • 免费使用：DY Board 永久免费，无任何功能限制或内购。
  • 本地优先：所有板书、批注、展台画面与照片仅在本机处理，绝不上传任何服务器。
  • 开源可信：完整源代码以 MIT 协议公开，可自由审阅、分发与二次开发。
  • 安装包校验：发布包经 Cosign 无密钥签名，可验证来源、杜绝被篡改。
  • 无账号体系：软件不收集个人信息，无需注册即可使用全部功能。
  • 免责声明：软件按“现状”提供，开发者不对使用过程中的任何直接或间接损失负责。

为什么做这件事

课堂上的工具，本该简单、顺手、可靠。DY Board 把白板书写、展台批注、课程表、时钟与倒计时收敛进一块乳白液态玻璃界面，让老师打开即用，不必在多个软件之间来回切换。

它不追踪你、不索取你的数据、不向你收费。如果你觉得有用，欢迎在 GitHub 上点个 Star，或提交 Issue 一起把它做得更好。

想参与贡献？ DY Board 是开源项目，任何人都可以通过 Pull Request 提交改进。无论是界面细节、新功能，还是文档翻译，我们都欢迎。
