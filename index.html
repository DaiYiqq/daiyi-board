把任意屏幕，变成你的课堂白板

DY Board 是专为教学设计的一体化白板与展台演示软件。乳白液态玻璃界面，对标 Apple 的纯净体验——打开即用，多平台免费。

免费下载 在线体验（网页版） 在 GitHub 查看源码

界面

乳白液态玻璃，纯净如 Apple

底栏、按钮、浮层、菜单、设置、展台控件，统一为乳白半透明液态玻璃——细边高光、柔和阴影。黑 / 白双主题始终保持清晰可读。

全局统一 · 黑 / 白双主题 · 悬停流光

文档摄像展台

把纸质讲义，投上大屏

枚举并切换摄像设备，显示真实分辨率与帧率。支持拍照存档、左右旋转、镜像、冻结、自动与高清分辨率请求，并可在画面任意位置实时批注。视频与照片仅在本机处理，绝不上传。

本机处理 · 实时批注 · 隐私优先

课程表 · 教学工具

课程表网格，自动识别当前节次

节次 × 星期网格，支持单双周两套课表；按系统时间自动识别上课 / 休息 / 已下课，并提示距下节课的分钟数。全屏时钟、课堂倒计时、激光指示、跟随指针的屏幕放大镜一应俱全。

单双周 · 实时状态 · 课堂工具箱
